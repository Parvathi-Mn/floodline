1. **YAML: YAML ain't markup language**: 
It is a human readable data serialization language used to store and exchange data.
Commonly used for: files and data representations.

2. **kerala.yaml**:
   It contains id, name, languages, emergency_numbers, districts

3. **Data collection from**:
Open-Meteo for live weather and forecasts. It needs no API key, which makes setup easier for people who clone your repo. Its flood API is also worth exploring.
IMD district rainfall warnings (orange/red alerts) for the alert level.
KSDMA (Kerala State Disaster Management Authority) for hazard maps, shelter information, and the official alert style.
